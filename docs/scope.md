# WAKU Scope

## v0.1 でやること

1. 空き枠を開放する（管理者）
2. 空き枠を見る（客）
3. 仮リクエストする（客）
4. リクエストを確認する（管理者）

以上。

時間粒度: **15分刻み**。

## 状態の意味

| status | 客に見える | 意味 |
|---|---|---|
| `closed` | × | 非公開（初期値） |
| `open` | ○ | 公開中・受付可 |
| `requested` | × | 仮リクエスト入った |
| `confirmed` | × | 確定済 |

**初期状態が closed である理由：**
WAKU は「管理者が開放した枠だけ見せる」アプリ。
データ作成時点で公開されていてはならない。
明示的な開放行為があって初めて open に遷移する。
